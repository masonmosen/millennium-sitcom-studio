# 模型、参数与分镜时长硬性规范（Model & Parameter Spec）

## 1. 生图模型与参数（角色设定图 & 5 张分镜首帧图）
- **指定生图模型**：默认使用 **`Nano Banana 2`**（如需对比面部细节可选用 **`GPT Image 2.5`**）。
- **固定参数**：`aspect_ratio="4:3"`（`2048×1536`），`quality="medium"`。
- **参考图纯净原则**：
  - 生成**单人多视角角色设定图**时：`reference_image_urls` 仅传入该角色的真实面部/全身参考图（左侧生成高细节面部半身特写，右侧生成正/侧/背全身三视图，暖米色纯色背景，1:7.5 正常成人头身比）。
  - 生成**5 张分镜首帧图**时：`reference_image_urls` 严格仅传入已确认的**两位主角单人设定图**（及新场景空镜布景锚点图），**严禁混入旧剧集画面或其他废稿**，防止人物串脸。

## 2. 生视频模型与 5 镜精确时长（5 张分镜首帧图 → 5 段有声视频）
- **指定生视频模型**：固定使用 **`Seedance 2.5`**（首帧图驱动模式：将已确认的 4:3 分镜首帧图传入 `start_frame_image_url`，**严禁同时叠加人物大头照到 `reference_image_urls`**，彻底杜绝广角镜头出现“大头娃娃”比例失调）。
- **固定参数**：`aspect_ratio="4:3"`（分辨率 `1112×834`），必须开启原生语音与音效 `sound="on"`，固定机位（Locked camera，零推拉摇移缩放），严禁背景音乐（Strictly NO background music / score / instruments），生成阶段严禁原生烧录字幕（NO subtitles）。
- **5 个分镜的机位调度、精确秒数与内部时间轴（总长严格 30.0 秒 = 6s + 6s + 6s + 7s + 5s）**：

### 镜头 1（0–6s，`duration_sec=6`）· 双人中全景主镜头（Master Two-Shot，建立与铺垫）
- 机位：大腿中部以上入画的 4:3 平视中全景，左角在左、右角在右，严格锁定 180 度第四面墙轴线。
- 时间轴：`0.0s–0.4s` 起始动作与道具交互；`0.4s–4.6s` 左角用美式英语说出约 15–18 词的铺垫台词；`4.6s–6.0s` 对方停顿反应 + 现场观众轻笑声（Light studio audience chuckle）切入并干净淡出。

### 镜头 2（6–12s，`duration_sec=6`）· 单人中近景（MCU Single，反驳与荒谬逻辑）
- 机位：腰部以上入画的单人中近景（通常为右侧角色在沙发/卡座/工位上，视线朝画面左侧回应）。
- 时间轴：`0.0s–0.4s` 角色耸肩或举起手持道具；`0.4s–4.6s` 用美式英语说出约 15–18 词的冷幽默反驳台词；`4.6s–6.0s` 保持理直气壮的微表情 + 现场观众中等笑声（Moderate studio audience laugh）自然淡出。

### 镜头 3（12–18s，`duration_sec=6`）· 双人中景对峙（Medium Two-Shot，冲突升级与关键道具音效）
- 机位：双人同框中景，左角急切阻止，右角准备操作关键年代道具。
- 时间轴：`0.0s–0.3s` 左角前倾或指着证据；`0.3s–4.2s` 左角用美式英语说出约 15–18 词的警告台词；`4.2s–4.4s` **触发关键实景音效（Practical SFX，如座机按键音 + 电脑死机声、老式诺基亚提示音、录像机退带声）**；`4.4s–6.0s` 两人震惊反应 + 现场观众惊呼与爆笑。

### 镜头 4（18–25s，`duration_sec=7`）· 单人中近景（MCU Single，核心包袱揭晓 Payoff）
- 机位：腰部以上入画的左侧角色单人中近景，展示灾后惨状道具（如只有一首歌的 CD-R、400 美元厚账单、未倒带的 VHS 磁带）。
- 时间轴：`0.0s–0.5s` 角色绝望瘫回椅背并举起/翻开关键道具；`0.5s–5.0s` 用美式英语说出全片最强笑点台词（带自然喜剧停顿）；`5.0s–7.0s` 角色生无可恋注视前方 + **全场观众哄堂大笑（Full hearty studio audience laugh，留足 2 秒笑声空间）**。

### 镜头 5（25–30s，`duration_sec=5`）· 双人中全景收尾（Master Two-Shot Button，冷幽默补刀与定格）
- 机位：回到与镜头 1 完全一致的双人中全景主镜头机位。
- 时间轴：`0.0s–0.3s` 右角放下道具看向左角；`0.3s–3.1s` 右角用美式英语说出简短精辟的冷幽默补刀台词（约 10–14 词）；`3.1s–5.0s` 左角缓慢转头朝向第四面墙摄影机镜头定格（Classic deadpan sitcom freeze/hold）+ 现场观众温暖笑声与掌声自然衰减收尾。

## 3. 分镜首帧图三项自检与修正
1. **头身比例**：必须为 1:7.5 至 1:8 正常成年人比例（大腿中部或腰部以上入画，严禁大头娃娃畸变）；
2. **取景边界**：严格框在房间三面墙内，严禁顶部露出摄影棚灯架或地面胶带；
3. **道具物理朝向**：角色看手机、账单、菜单时，屏幕/字面必须朝向角色自己的眼睛，**仅手机背面后盖或纸张背面朝向摄影机镜头**（如发现屏幕反朝镜头，立即调用局部编辑将道具旋转 180 度修正）。
